# SendScriptInstagram

Código para enviar o Script inteiro de Shrek ou Bee Movie para seus amigos ou grupos do Instagram

## Utilização

Abra [shrekSendScript.js](https://github.com/Psm0015/SendScriptInstagram/blob/main/shrekSendScript.js)
Ou
Abra [beeMovieSendScript.js](https://github.com/Psm0015/SendScriptInstagram/blob/main/beeMovieSendScript.js)

Copie todo o conteúdo (clique em raw -> ctrl+a -> ctrl+c)

No Instagram Web abra o console do Browser

|  ⚠️ Aviso importante, numa atualização recente do Google Chrome, está sendo impedido que qualquer script seja colado no Console.|
|--|
|  ***Para contornar esse problema, o console do desenvolvedor espera receber um confirmação textual escrevendo no console: "allow pasting"***| 
|Após isso será permitido colar e continuar a execução do script|


Cole o código no console e aperte Enter
